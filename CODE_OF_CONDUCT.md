# Code of Conduct

Hardgate is a technical project, and participation should remain safe,
respectful, and useful. This code applies in repository discussions, issues,
pull requests, reviews, project-managed communication, and when someone is
representing the project elsewhere.

## Expected behavior

Participants are expected to:

- treat people with respect, including when reviewing code or disagreeing;
- discuss the work with clear, good-faith technical reasoning;
- welcome different backgrounds and levels of experience;
- protect private information and avoid exposing credentials or personal data;
- follow maintainer requests about keeping a discussion focused and safe.

## Unacceptable behavior

Harassment, discrimination, threats, intimidation, stalking, personal attacks,
sexualized comments or attention, doxxing, publishing private information,
deliberate disruption, retaliation, and bad-faith reporting are not acceptable.
The same applies to unwanted contact after someone asks for it to stop.

## Maintainer response

Maintainers may clarify expectations, ask for content to be changed or
removed, issue a warning, limit participation temporarily, or permanently
remove participation. The response should be proportionate to the impact,
severity, and pattern of the behavior. A maintainer involved in a report should
step back from deciding it when practical.

Do not put sensitive details in a public issue. Use a private reporting route
already provided by a project maintainer or the repository platform; do not
guess or publish private contact details. Maintainers will keep reports
confidential where practical and will explain the next step through the
available private channel.
